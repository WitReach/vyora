# Vyora

Open-source headless commerce platform for modern brands.

Built with Next.js (frontend) and Laravel (API).

---

## 🚀 Vision

Vyora aims to become a scalable, developer-first alternative to traditional ecommerce platforms — giving full control over storefront and backend logic.

---

## 🧩 Architecture

* Frontend → Next.js (vyora-frontend)
* Backend → Laravel API (vyora-api)
* Headless architecture (API-first)
